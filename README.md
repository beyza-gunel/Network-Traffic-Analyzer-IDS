# Network Traffic Analyzer & Intrusion Detection System

Bu proje, PCAP dosyalarındaki ağ trafiğini analiz etmek ve
şüpheli ağ aktivitelerini belirli güvenlik kuralları ile tespit etmek
amacıyla geliştirilmiş masaüstü tabanlı bir Network Intrusion Detection
System (NIDS) uygulamasıdır.

## Kullanılan Teknolojiler

- Python
- Scapy
- PySide6
- Pandas
- Matplotlib
- NetworkX

## Mevcut Özellikler

- PCAP dosyası okuma
- Paket bilgilerinin ayrıştırılması
- TCP, UDP ve ICMP trafik analizi
- Trafik istatistikleri
- Port Scan Detection
- SYN Scan Detection
- ICMP Flood Detection
- DNS Anomaly Detection
- Unusual Port Activity Detection
- Traffic Burst Detection
- Risk Score hesaplama
- LOW / MEDIUM / HIGH / CRITICAL risk seviyeleri

## Proje Durumu

Geliştirme devam etmektedir.
